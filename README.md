# Railway Ticket Helper

A lightweight Chrome/Android-friendly helper for preparing Bangladesh Railway booking details.

## Web app
Upload these files to a GitHub Pages repository and open the Pages URL on Android.

## Chrome extension
1. Open Chrome on a desktop.
2. Go to `chrome://extensions`.
3. Enable Developer mode.
4. Choose Load unpacked.
5. Select this folder.

The tool does not automate CAPTCHA, OTP, payment, seat confirmation, or repeated requests.
